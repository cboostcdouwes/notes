Solid boxes: the detector's latest output, one frame behind the image because of inference latency. Dashed: the tracker's prediction for now, which is what fires the triggers. Each box is turned into belt positions by assuming a 140 mm pallet height; the tracker (lead and trail edge, belt-slip rate) bridges missed frames. Boxes are simulated from the true geometry with jitter, 2% misses, and touching pallets that the model sometimes sees as one. Trigger error = true minus estimated position when a station camera fires.

Each pallet's images appear here once it has passed the scanner.

Concept simulation, not a camera datasheet. Geometry, colours, wear, lighting, lens and camera figures are assumptions. The images are ray-traced on the GPU from the same geometry the 3D view shows, so what each setting can or cannot see is real for this geometry; image quality is not. Line pitch equals the across-belt pixel size (square pixels), so 4k means ~0.3 mm lines and about 16× the work of 1k. Depth of field uses a thin lens focused on the belt centre, 7 µm pixels.
