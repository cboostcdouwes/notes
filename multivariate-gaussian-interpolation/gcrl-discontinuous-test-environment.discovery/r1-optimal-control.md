# Round 1, generator J: optimal control, dynamic programming, numerical analysis

## Reformulations
- Optimal control: minimum-time problem with state constraints; value = minimal time T(s,g); Q* = r + γ·V*(f(s,a),g), V* = γ^N; exact Q (R8a) = exact f (R11) + exact step count N at the next state.
- Viability theory: discrete-time minimal time function / capture basin; level sets of N are k-step backward reachable sets Pre^k(goal ball).
- PDE / viscosity: eikonal equation with obstacles, Ω-constrained viscosity solution = geodesic distance d (R8b); discontinuity types: jumps where Soner's inward-pointing condition fails (thin walls), kinks at shadow lines and cut locus.
- Computational geometry: Euclidean shortest path among obstacles (visibility graph, shortest-path map) for d; minimum-link path with bounded link length for N under straight steps of length ≤ r (near-quadratic with holes; several variants NP-hard) — exact N under "natural" dynamics is hard in general; with wall sliding a step is not straight and can wrap a corner.
- Nonsmooth mechanics: wall sliding is a sweeping process (Moreau); discrete form = catch-up algorithm x⁺ = Proj_free(x + a).
- Numerical analysis: code verification with manufactured solutions / benchmark problems (choose problems whose exact answer is known).
- Wider: verification benchmark for approximators of nonsmooth/discontinuous value functions with exact jump loci.
- Narrower: exact N and d only near walls and along chosen slices.
- Inverted: choose the value/geometry first and derive the environment (closed-form truth by construction), or a secretly discrete world (navmesh) where truth is graph search.
- Universal bound: any dynamics with per-step travel ≤ r has N(s,g) ≥ ceil(d(s, goal set)/r).

## Worked-out options
J1. Tangent-graph geodesic distance in JAX (exact d, R8b) — C-space of a circle among polygon walls = rounded polygons; shortest paths = tangent segments + arcs around radius-ρ circles at convex vertices; per layout (numpy) bitangent graph + Floyd–Warshall; per query (JAX) tangents from x and g, batched visibility tests, min over direct and routed paths; arbitrary goals, exact to float precision. Variants: zero-thickness segment walls (capsules, endpoint circles only); point agent drawn as circle (ρ = 0, classic visibility graph, ~30 lines). Caveats: partly hidden goal ball needs d to the set; arc wrap bookkeeping. Sources: https://en.wikipedia.org/wiki/Visibility_graph, https://arxiv.org/pdf/2504.03747, https://lavalle.pl/planning/node271.html; CPU cross-check extremitypathfinder (license believed MIT), pyvisgraph (MIT). Cost: medium, 150–300 lines; base for J3, J5, J8.
J2. Exact k-step backward reachable sets as an arc/segment arrangement (exact N by discrete-time reachability) — R_0 = goal ball, R_k = Pre(R_{k-1}) ∪ R_{k-1} as CGAL 2D arrangements with circular arcs and exact algebraic numbers; export boundaries to JAX for point-in-region tests. "Blocked = stay" or straight moves give offset arcs + shadow segments; sliding raises curve degree. Goals from a fixed finite set (precomputed per goal). Sources: CGAL circular-arc arrangements https://doc.cgal.org/5.6/Arrangement_on_surface_2/Arrangement_on_surface_2_2circular_arcs_8cpp-example.html, Minkowski sums https://doc.cgal.org/4.9/Minkowski_sum_2/group__PkgMinkowskiSum2.html (GPL/LGPL, not verified; thin Python bindings); pycvxset (AGPL, convex only) https://arxiv.org/pdf/2410.11430. Cost: high; C++/CGAL dependency.
J3. Certified staircase bracket with refinement only where undecided — lower bound L = ceil(d/r) (J1, any dynamics); upper bound U = steps of a constructive policy (step r along the geodesic, or best-of-action-grid lookahead); exact where L = U (N integer); refine disagreements (slivers behind convex corners) by branch-and-bound lookahead over the action disk with L as admissible heuristic; SIVIA-style inner/outer paving; edge positions by bisection along query lines; also exact max_a Q. Sources: https://www.ensta-bretagne.fr/jaulin/paper_hull.pdf, https://scitepress.org/PublishedPapers/2011/35360/pdf/index.html, https://arxiv.org/pdf/1706.04542. Cost: medium–high; may leave a small reported undecided set.
J4. Manufactured-solution layout ladder — layouts with hand-derivable exact d, N, Q (empty room, one thin wall, slit/doorway, U-trap, two rooms) as unit tests for the general truth code and graded critic difficulty; symbolic discontinuity positions. Sources: Roache MMS https://springerlink.bibliotecabuap.elogim.com/chapter/10.1007/978-3-319-70766-2_12, https://arxiv.org/pdf/1501.01518. Cost: low per layout; closed form only for simple layouts unless combined with J5.
J5. Eikonal-consistent ("geodesic-step") dynamics, so N = ceil((d − ε)/r) exactly — the step moves up to |a| along the shortest free path from s toward the target s + a; subpaths of shortest paths are shortest, so N is closed form and Q follows from J1's d at f(s,a). Serves R3/R6: dynamics discontinuous in a (target just behind a thin wall → detour, travel only r along it), motion wraps corners, staircase level sets are exact offset curves of d. Source: constrained viscosity / DPP https://arxiv.org/pdf/2303.10705. Cost: low–medium on top of J1 (short-range geodesic per step); non-standard "path-following" dynamics, weaker transfer to contact tasks.
J6. Separable rectilinear world — square agent, axis-aligned box walls, |a_x|,|a_y| ≤ r applied as clamped x move then clamped y move (per-axis sliding); Pre of a union of boxes is a union of boxes, so every R_k is exact with rational coordinates; N, Q, d (L1/L∞), f exact with simple code (R9). Departures: square not circle (R2); x-then-y asymmetry; axis-aligned discontinuities only (may be too easy for axis-aligned critics). Source: https://lavalle.pl/planning/node271.html. Cost: low.
J7. Catch-up (projection) dynamics with steps below the free space's reach — f(s,a) = Proj_free(s + a); rounded C-space is prox-regular (constant ≈ ρ) except at cusps; for |a| < ρ and walls thicker than r the projection is unique, closed-form, cheap, batched, exact (R11), keeps tangential motion (R6), no tunnelling; larger r via K substeps (catch-up → sweeping process). Fixes f only; N still needs J2/J3 or J5. Sources: https://arxiv.org/pdf/2308.08093, https://arxiv.org/html/2501.04781v1, https://arxiv.org/pdf/2407.09354. Cost: low, ~50 lines; cusps need care.
J8. Discontinuity catalogue: one layout containing every viscosity-solution feature with exact loci — (1) value jumps across thin walls (Soner), (2) shadow rays from wall endpoints (gradient kinks), (3) cut locus where two routes tie (hyperbola branch; argmax over actions switches there, driving overestimation), (4) staircase edges (offsets of d at multiples of r), (5) action-space jumps of Q at fixed s where a pushes into a wall; E11/E14 report edge error per feature type. Sources: https://arxiv.org/pdf/2110.08530, https://arxiv.org/pdf/0901.3977, https://arxiv.org/pdf/2303.10705. Cost: low–medium on top of J1.

## Other titles
- Shortest-path map per goal (Hershberger–Suri continuous Dijkstra) + JAX point location for exact d
- GPU level-set / semi-Lagrangian value iteration (hj_reachability) as approximate cross-check, exact correction near walls
- Fast marching (scikit-fmm) on a fine grid as sanity check of d
- Thin walls only + point agent: smallest exact code
- "Blocked move = stay" dynamics: N = bounded-link min-link path, BFS over visibility-disk sets
- Navmesh world: convex cells, per-cell motion, exact truth by graph search
- Kruzhkov transform V = 1 − e^(−T) or γ^N for bounded comparable truths
- Exact 1D slices: truth only along probe lines by root-finding jump positions
- Rational-coordinate layouts with sqrt-free predicates
- Lipschitz branch-and-bound over the action disk for exact max_a Q
- dt → 0 consistency check: N·r → d as r shrinks
- Hybrid automaton with exact time-of-impact sweep-and-slide in a fixed-length JAX loop
- Offline exact "edge atlas": discontinuity curves as parametric segments/arcs, smooth values between

## Key finding
With natural straight-step or sliding dynamics, exact N for arbitrary layouts is a hard computational-geometry problem; it becomes exact via certified bounds (J3), changed dynamics making N a closed form of d (J5), or restricted geometry (J4, J6). Exact d (R8b) is cheap and batched via the tangent/visibility graph (J1).
