# Round 1, generator H: robotics motion planning, computational geometry, game/physics engines

## Reformulations
- Robotics: point in C-space with walls inflated by the agent radius (Minkowski sum; circle among segments = point among capsules). R8b = cost-to-go / navigation function; R8a = discrete-time minimum-time reachability, B_k = Pre(B_{k-1}) from the goal region.
- Computational geometry: R8b = Euclidean shortest path among polygonal obstacles (visibility graph, shortest path map by continuous Dijkstra); R8a ≈ minimum-link path with a length bound per link (no standard algorithm found for that variant).
- Game/physics engines: dynamics = character controller (swept-shape CCD / time of impact, then collide-and-slide / clip velocity); step truth = navmesh pathfinding.
- Finding: the staircase is NOT ceil(geodesic / step length). Counter-example: a path of length exactly 2r bending at a convex corner 0.5r from the start needs 3 steps (the midpoint would have to see both ends). Exact R8a needs reachable-set geometry, a restricted world, or a different step definition.
- Wider: any exact oracle for "value under constraint geometry" (HJ reachability, contact-implicit dynamics with known optimum).
- Narrower: only edge positions need to be exact (exact discontinuity curves: arcs around pivots, shadow lines through vertices).
- Inverted: redefine "one step" so the staircase is shaped by obstacles, not quantization (link distance); or discount by path length (semi-MDP) so the staircase disappears and R8a collapses into R8b.

## Worked-out options
H1. Tangent-visibility-graph oracle in JAX (C-space inflation) — R8b. Capsule walls (segments inflated by agent radius); shortest paths = bitangent lines + arcs around endpoint disks; offline Floyd–Warshall over tangent nodes; query = min(direct if visible, min over visible u, v of |p−u| + D(u,v) + |v−g|); segment-vs-capsule visibility over a static wall array, vmappable; polygonal-walls + point-agent variant avoids arcs. Sources: pyvisgraph (MIT) https://pypi.org/project/pyvisgraph, extremitypathfinder (MIT) https://extremitypathfinder.readthedocs.io/en/stable/3_about.html. Cost: ~150–250 lines; arc lengths need care; float-exact; O(V^2) per query; R8b only.
H2. Discrete-step wavefront ("quantized continuous Dijkstra" / pivot propagation) — exact R8a without sliding. Boundaries of B_k are arcs of radius jr (+ goal radius) around pivots and shadow lines through obstacle vertices; pivots = goal, obstacle vertices, and points pivot + jr·unit(vertex − pivot) along taut edges (finite for bounded k); N(p,g) = minimum over visible pivots (lower envelope, vmappable); Q* = γ^(1+N(f(s,a),g)). Sources: continuous Dijkstra / shortest path map https://arxiv.org/pdf/2010.09115, GPU cone rendering https://arxiv.org/abs/1805.08500. Cost: research risk (pivot characterisation is a conjecture, needs proof or brute-force check vs H4); sliding excluded; per goal.
H3. Axis-separated tile world (platformer collision) — exact everything by rectangle arithmetic. Square (AABB) agent, axis-aligned rectangular walls from an ASCII tile map, action box [−r, r]^2, per-axis resolution (x then y, each clipped) giving sliding (R6); one-step image and pre-image of rectangle unions are rectangle unions; coordinate compression + BFS gives exact N per goal; dynamics = two clamps. Sources: https://gamedev.net/tutorials/programming/general-and-gameplay-programming/swept-aabb-collision-detection-and-response-r3084, https://arxiv.org/pdf/2106.14185. Cost: breaks R2's circle (should); anisotropic; x-then-y artefact; R8b needs H1 over rectangle corners; very readable (R9).
H4. Exact-arithmetic backward reachable sets (Minkowski sums + visibility clipping) — general R8a by brute force. Per goal, B_{k+1} = Pre(B_k) with exact 2D geometry (Minkowski sum with step disk or polygonal step set, visibility clipping, booleans on arc polygons); point-in-polygon queries; polygonal (octagon) action set keeps everything piecewise-linear and rational-exact; verifies H2. Sources: CGAL Minkowski sums (GPL-3.0+ or commercial) https://doc.cgal.org/4.8/Minkowski_sum_2/group__PkgMinkowskiSum2.html, Wein exact offsets https://www.cgl.cs.tau.ac.il/projects/exact-and-approximate-construction-of-offset-polygons/, Raković & Mayne https://folk.ntnu.no/skoge/prost/proceedings/cdc-ecc05/pdffiles/papers/0199.pdf. Cost: CGAL C++/GPL, thin bindings (Shapely approximates arcs); sliding makes Pre() much harder; per goal, heavy; hard to read.
H5. Waypoint actions / link-distance world (inverted: redefine the step). Action = displacement of any length; move straight until target or wall (stop or slide); step count = link distance; Q* = γ^(link distance); level sets = window partition (extensions of obstacle edges through vertices), staircase shaped purely by obstacles; exact by iterated weak-visibility regions (Shapely, exact for point/polygon goals). Sources: Suri 1990 https://www.bohrium.com/paper-details/on-some-link-distance-problems-in-a-simple-polygon/812459122971639809-13750, Mitchell–Rote–Woeginger https://page.mi.fu-berlin.de/rote/Papers/abstract/Minimum-link+paths+among+obstacles+in+the+plane.html, SoCG 2026 https://drops.dagstuhl.de/storage/00lipics/lipics-vol367-socg2026/html/LIPIcs.SoCG.2026.45/LIPIcs.SoCG.2026.45.html. Cost: changes the task (few-step episodes, unbounded speed); less like contact control; holes make algorithms complex.
H6. Collide-and-slide kinematic controller with analytic time of impact — dynamics for R1, R6, R10, R11. Sweep circle along a, earliest TOI against capsule walls, move to contact minus skin, remove normal component, repeat 2–4 iterations (lax.fori_loop) with crease direction in corners; brute force over static walls, vmapped. Sources: Fauerby collide-and-slide https://arxiv.org/pdf/1211.0059, Quake 3 PM_SlideMove https://sources.debian.org/src/ioquake3/1.36%2Bsvn2287-1/code/game/bg_slidemove.c, Box2D TOI (MIT) https://box2d.org. Cost: ~100–150 lines; epsilons are where bugs hide; sliding makes exact R8a harder; readable.
H7. Projection dynamics through exact signed distance functions (sweeping process / position-based dynamics). s' = Π_free(s + a) via analytic SDFs of inflated walls: s' = p − min(sdf(p),0)·∇sdf(p); tangential motion kept (R6); closed form, vmappable, differentiable a.e.; SDF gives distance-to-wall feature. Sources: Moreau–Jean https://hal.archives-ouvertes.fr/hal-01349847/file/JJM2c.pdf, Quilez 2D SDFs https://iquilezles.org/articles/distfunctions2d, PBD https://matthias-research.github.io/pages/publications/posBasedDyn.pdf. Cost: tunnels through walls thinner than ~2r (needs thickness ≥ step rule or a swept check); non-unique projection on medial axis inside thick walls; reachable sets differ from swept motion; simplest code.
H8. Velocity-obstacle maps of action-space edges — exact discontinuity positions over actions. For fixed s, actions hitting wall i within one step form a truncated velocity obstacle (tangent lines + arc); cells where f(s,·) is smooth; Q*(s,·,g) jumps only on these boundaries or on pulled-back staircase boundaries; exact closed form for Q(s,a) plots, edge scoring, max-over-actions checks; combine with any state-space oracle. Sources: RVO2 (Apache-2.0) https://github.com/snape/RVO2, https://github.com/snape/RVO2-Java. Cost: an evaluation instrument only, ~80 lines; under sliding, pulled-back staircase edges need composition.

## Other titles
- Off-the-shelf JAX rigid-body engine (Jax2D/Kinetix MIT; MJX/Playground Apache-2.0); exact R8a infeasible without a separate kinematic truth model
- HJ minimum-time with hj_reachability (grid level sets; blurs edges)
- Fast-marching eikonal field (scikit-fmm; grid approximation)
- Navmesh + simple stupid funnel string pulling (Recast/Detour, zlib by memory, unconfirmed): exact Euclidean geodesic
- Per-goal shortest path map with point location
- Rooms-and-doors world: convex rooms joined by portals; exact geodesics via portal funnels
- Thin-wall world: zero-thickness segment walls, point agent
- Disk-only obstacles world: closed-form bitangent geodesics
- Lethal hazard regions instead of walls: termination makes discontinuities without blocking motion
- Billiard reflection response instead of sliding
- Polygonal (octagon) action set so reachable sets stay piecewise-linear
- Semi-MDP discount by path length (γ^length): staircase vanishes, R8a = R8b
- High-resolution rasterised truth with exact analytic edge correction (multi-channel SDF trick)
- GPU cone-rendering lower envelope (Kallmann) as texture lookup per goal
- Conservative-advancement TOI (Box2D-style)
- GJK/EPA convex collision for arbitrary convex walls
- Velocity-level LCP contact (Stewart–Trinkle)
- Sampled roadmap (PRM / visibility-PRM) certified by exact visibility checks
